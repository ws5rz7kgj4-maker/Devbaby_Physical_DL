## 需要更正的旧解读

1. “整个项目还没有成功率曲线”不准确。早期身体控制已有曲线；缺失的是**修复后的新世界模型**曲线。
2. “随机动作导致旧世界模型学不到”没有被证明。训练缺陷足以使原因分析失效，pilot 中原策略覆盖均值也不差。
3. “只要损失下降/梯度有限就训练正确”不成立。旧检查漏过了 `grad=None`，部分参数一直保持初始化。
4. “补丁已验证”只表示当前 GPU 单步机制验证。不能扩展成完整 GradScaler 流程、长期训练或控制通过。
5. “全部编码器正常，只是 GRU 有问题”不准确。逐参数证据另有 18 个 encoder 张量受影响。
6. “训练更多就更快适应”不符合早期结果。成熟模型朴素适应会退步；补充协议检验了若干缓解方案。
7. “有几个年龄点就是 scaling law”不成立；没有已验证的多尺度规律。

## 中止、失败和数据保留

第一轮世界模型失败后只导入校验过的原始训练数据，模型重新初始化。后续命名含 `Fixed` 的历史包修复的是非有限梯度恢复，**仍包含后来发现的缓存缺陷**。

冻结诊断的第一次云作业在开始发布状态时因旧输出仓库写权限失败，评估尚未开始。随后使用独立私有输出仓库通过写入/读取预检后完成诊断。失败作业没有可用结果，不与成功重跑合并。

世界模型大作业的最后一次历史分析快照曾记录 837/1,762 个物理面板、14,712 个计分试验；本次未重新遍历并核算所有物理面板，因此该计数只作为历史进度记录，不进入当前汇总表或正式统计。1,762 是原计划数量，不是完成量。外部取消后的 `state.json` 可能保留 running，不能单凭该文件推断仍在运行。

已有模拟数据和检查点保留作审计。补丁后的新结果必须使用新的运行身份，不能覆盖旧故障证据或将旧权重续训伪装成从零学习。
