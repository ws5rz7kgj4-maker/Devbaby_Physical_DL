# 训练缺陷、证据和修复边界

[English](../en/TRAINING_BUG.md) · [首页](../../README.zh-CN.md)

## 已确认的问题

后期世界模型的 `WorldModel.loss` 在同一个 FP16 autocast 上下文中，先以 `torch.no_grad()` 执行 burn-in，再执行可训练的前向计算。匹配对照复现了该实现的权重缓存复用导致部分参数没有梯度。其他参数仍可更新，因此总损失下降、梯度范数有限、更新计数递增都不足以证明整个模型在学习。

这项结论针对存档实现和记录的 PyTorch 2.6.0 / L4 环境；不是对所有 PyTorch 版本或所有 AMP 用法的泛化判断。早期身体预测实验使用不同模型/训练路径，不能仅因本缺陷就撤回其结果。

## 证据链

1. 严格加载 seed 0 与 seed 1 的年龄 0、65,536 检查点；每个均记录 4,096 次更新。
2. `dynamics` 与 `filter` 各四个参数张量逐元素完全相同，优化器没有它们的状态。参数集合非空，排除了空前缀统计造成的“零变化”。
3. 完整逐参数记录还显示：另有 18 个 encoder 张量同样未变且无优化器状态。encoder 的四个 LayerNorm 张量有变化；不可笼统写“编码器训练正常”。
4. CPU FP32、真实合成感官批次中，关键参数有有限梯度和单步更新，保存/重载一致。
5. 同初始权重和数据的 GPU 三条件单步实验复现了缓存开关差异。

| GPU 条件 | 缺失梯度张量 / 44 | 有限梯度张量 / 44 | 非零单步更新张量 / 44 | 两个 GRU 的 8 个张量 |
|---|---:|---:|---:|---|
| FP32 | 0 | 44 | 44 | 均有梯度、均更新 |
| FP16，缓存开启 | 26 | 18 | 16 | 均无梯度、均未更新 |
| FP16，缓存关闭 | 0 | 44 | 42 | 均有梯度、均更新 |

关闭缓存后的两个 `image_start` 参数在这次未使用 GradScaler 的 FP16 单步中梯度为零、未更新。因此本证据不能概括为“关闭缓存后所有参数都更新”。原长期检查点中的这两个参数曾有变化。

原始证据：[CPU](../../results/raw/parameter_cpu_result.json)、[GPU](../../results/raw/parameter_gpu_result.json)。逐参数 CSV 与字段解释见[数据说明](../../results/README.md)。

## 补丁

已归档的 [apply_gradient_fix.py](../../code/gradient_audit/apply_gradient_fix.py) 对指定原项目精确修改：

```python
with torch.autocast(
    device_type=device.type,
    dtype=torch.float16,
    enabled=use_amp,
    cache_enabled=False,
):
    ...
```

梯度裁剪前，对预期参与当前损失的可训练参数检查 `grad is None`，缺失则直接报错。当前 WM/BC 路径预期所有可训练参数参与；未来可选头或条件分支必须显式维护预期集合，不能把合法未使用参数误报为故障。

脚本更新数值版本标识，验证源码匹配和语法，保存备份，拒绝覆盖既有备份/重复应用。它只改源码，不提交云作业。此仓库保留原始历史包，不把它们伪装成已经验证的修复后训练发布版。

## 什么已验证，什么没验证

| 项目 | 状态 |
|---|---|
| 历史 seed 0/1 参数冻结与无 optimizer state | 已验证 |
| 匹配 GPU 缓存开/关复现 | 已验证 |
| 关键循环模块梯度与单步更新恢复 | 已验证 |
| 原完整 `optimizer_update` + GradScaler 重试/回退/恢复 | 尚无修复后完整回归证据 |
| 修复后小样本预测与简单物理任务 | 尚无完成证据 |
| 修复后全规模重训和泛化曲线 | 尚无完成证据 |

过去的 overflow 恢复测试处理的是非有限梯度，遗漏了 `grad=None`。这是实现与验收缺口，不能用随机探索困难来代替解释。后续必须先验证完整更新路径和每模块更新，再扩大计算规模。

## 对历史结论的修订

- 旧 AMP 世界模型的预测/控制数值保留为**有缺陷实现的描述性记录**，不能用于否定随机探索，也不能支持正常训练的学习规律、音频因果贡献或 scaling law。
- 模拟器生成的原始轨迹与标注不因该训练缺陷自动失效，可以在核对身份和划分后复用；旧受损模型不应作为修复后能力比较的初始化。
- 单独的 200 步 **FP32** 损失对照不经过这一 AMP 缓存路径。其预测质量问题仍然存在，不能宣称已被补丁解决。
- 早期身体预测/伸手实验另行审查，见[早期结果](EARLY_EXPERIMENTS.md)，不与后期缺陷实现混为一个模型。
