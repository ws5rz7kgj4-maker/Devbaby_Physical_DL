# 方法与指标口径

[English](../en/METHODS.md) · [首页](../../README.zh-CN.md)

本项目包含不同阶段的模型。早期身体预测与伸手控制实验见[早期实验](EARLY_EXPERIMENTS.md)；下述架构、任务和诊断主要对应后续 `DevBaby-worldmodel-v2`，不可把两个版本的成功率拼成同一条学习曲线。

## 研究问题

目标是检验：随机交互的持续性和噪声如何改变物理接触与状态变化的覆盖；这些经验是否帮助随机初始化的模型在新的物理情境中完成任务，并提高学习速度。语言与声音作为与交互共同出现的输入，其作用要由受控比较验证。

“发展年龄”指向训练开放的累计交互次数，不是生物年龄、语言熟练度或意识水平。最终主要指标应是独立情境上的物理任务成功率；图像预测误差、接触覆盖、候选动作排序均是不同的辅助指标。

## 完全合成，但并非没有设计先验

物理场景由 PyBullet 生成，包含刚体球、盒、圆柱及随机质量、摩擦、恢复系数、布局等属性。身体是力控制的球形末端执行器，含程序化的近距离抓取约束；没有关节手指或真实婴儿身体。

双固定相机产生 RGB；碰撞声由解析衰减振荡生成；养育者语音由 eSpeak NG 合成。当前版本随机选择物体、英语模板、声音、语速、音高和间隔，语句中的颜色、形状、材质依据场景属性。它是**随机化且有语义对应的合成语言**，不是与世界独立的随机词串。环境模板、传感器、身体和任务均带有人工设计假设；“从零学语言”不等于“系统没有任何先验”。

模型无预训练语言/视觉/音频权重，不接收文本、tokenizer 输出或转录标签。声音关联的学习不等价于语言理解、自主说话或意识产生。

## 数据与标签边界

每段 128 步经历记录 129 个观测时刻。控制为 8 Hz，物理仿真为 120 Hz，原始音频为 16 kHz。

| 内容 | 形状/含义 | 世界模型优化可见 |
|---|---|---|
| RGB | `[T+1, 2, 64, 64, 3]`，uint8 | 是 |
| 本体感觉 | `[T+1, 10]`：位置、速度、闭合、接触、yaw、抓持 | 是 |
| 动作 | `[T, 5]`：平移三维、抓取、yaw | 是 |
| 声音特征 | 混合声/碰撞声/语音各 `[T+1, 32, 16]` log-mel | 按实验组选择 |
| WAV | 三声道，混合/碰撞/语音 | 保存作审计；网络读取特征 |
| 物体真值 | 位置、旋转、速度、角速度、存在、接触、分割 | 否 |
| 场景与语言标注 | 材质、形状、尺寸、种子、相机、语句与时间 | 否 |

`actions[t]` 在观测 t 之后发出，可能通过延迟执行器影响 t+1 及后续观测。t+1 的声音特征总结刚结束的时间区间。转录与真值另存于 `annotations/`。

冻结表示上的 ridge 诊断探针使用标注拟合；任务构造、评分和特权参考控制器也使用真值。因此准确表述是“世界模型优化和学习规划器不输入物体标签”，而非“整个实验不使用标签”。

## 世界模型与规划

两幅图拼成六通道输入图像 CNN；声音 CNN 编码 log-mel；本体感觉与特征融合。隐藏维度 192，声音特征 48。`dynamics` GRUCell 根据五维动作推进潜在状态；`filter` GRUCell 根据当前感官观测更新状态。解码器预测图像和十维本体感觉。

训练包括后验重建、一步预测及最长 32 步的多步预测，图像运动加权和小的潜在分散正则；不使用任务奖励或物体标签损失。原协议批量 8、burn-in 8、每块 32 段经历及 256 次更新、16 块，合计每种子 65,536 次交互与 4,096 次更新。数据可以先生成，但重放只能读取当前年龄的经历前缀。

规划器接收当前观测和最终双视角目标图，通过 CEM 搜索动作块，每块重复 4 步。比较时距 8/32/64，名义每轮潜在转移预算 2,048、3 轮迭代。长时距意味着候选更少、动作变量更多，不能把比较解释为严格隔离时距或精确匹配 FLOPs。64 步超过训练最长 32 步，属于外推。

## 原正式协议：设计不等于结果

8 个训练种子；五组声音输入为 `full / silent / impact_only / speech_only / shuffled`。评估域为 `iid / new_physics / new_layout / occluded / material_shift`，任务为搬移、抬起、两物体堆叠、两物体排列、三物体排列。声音、规划时距和 hindsight goal-conditioned BC 的比较预先锁定于协议。

BC 从随机经历的未来图像构造 hindsight 目标并回归曾发生的动作，没有专家示范。特权脚本控制器可读取真值、执行器队列和目标，仅作工程可行性参考，不是学习模型。

物理成功要求指定物体在最后连续三个时刻均距目标小于 0.075 m；抬起还要求持有物体，其他任务要求释放，堆叠还要求指定物体接触。参考控制器或候选列表中的特权轨迹成功不能计入模型成功率。

原计划使用配对的训练种子和情境比较、交叉 bootstrap、六个主对比的 Holm 校正；缺失所需单元则不报告完整主检验。主运行后来被用户取消，且发现训练缺陷，因此这些是**原协议设计**，不是已完成有效统计推断。

## 延迟条件不能混用

当前世界模型的 `new_physics` 同时改变多项动力学属性，其中运动指令经 FIFO 延迟：IID 为 0 或 1 个控制步（0/125 ms），新物理为 3 步（375 ms）。它不延后奖励或训练标签，也不是隔离“仅延迟”的实验。

遗留代码另有养育者语音延迟选项，但归档早期正式/补充实验没有把它作为执行条件；早期正式协议该值为 0。已执行的运动延迟条件见[早期实验](EARLY_EXPERIMENTS.md)。当前 `PhysicalWorld._speak()` 覆写了遗留语音延迟逻辑；不能将这个代码选项写成已完成的语音消融或当前五个声音组之一。

## 诊断指标的精确定义

| 指标 | 定义 | 不能替代 |
|---|---|---|
| 接触时间占比 | 有物体接触的步数 / episode 步数 | 任务成功率、信息量 |
| 动作影响时间占比 | 同初始场景下，相对 idle 轨迹至少一物体偏移 >2 cm 的时间占比 | 每步新增信息、熵或互信息 |
| Object-region MSE | 起点与目标时刻可见物体 mask 并集上的归一化 RGB MSE | 位置误差、控制成功率 |
| Persistence | 始终预测起点图像，采用同目标和 mask | 学习的动力学模型 |
| 候选距离优势 | 候选的真实终点距离均值减去所选候选距离，单位 m | 完整 CEM 的成功率 |

动作影响含物体被移动后持续存在的位置差。pilot 运动阈值为 0.04 m/s，原数据覆盖统计用 0.03 m/s，不能直接合并这两个“运动率”。

动作错配诊断比较实际动作、零动作、倒序动作；倒序是先反转完整未来 64 步序列，再取时距前缀，不是符号取反，也不是逐时距前缀的反转。三者都与实际动作产生的目标帧比较，没有对应反事实模拟真值。

## 泛化、学习速度和 scaling law

后续确认性实验应预先固定新训练/测试种子，在相同情境上评估多个交互预算。成功率、曲线面积、达到预先定义阈值的交互量、相邻阶段成功率变化/交互量应分别报告；负增长和未达到阈值也要保留。阈值与最小有意义效应必须在正式测试前确定。

只有几个训练年龄点不构成 scaling law。当前没有跨模型规模、数据量、算力的经过验证的规律拟合，也没有修复后世界模型的可靠物理成功率曲线。
