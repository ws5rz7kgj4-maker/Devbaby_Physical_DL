# 局限、研究价值与下一步

[English](../en/NEXT_STEPS.md) · [首页](../../README.zh-CN.md)

## 已有工作的价值

目前的证据支持三个具体产出：一套可追溯的全模拟多模态实验流程；早期受限控制系统中“训练进步但继续适应可能退步”的结果及对照；以及后期世界模型部分参数未训练的复现与定位。这些足以形成公开研究记录和可复核的技术报告。

最值得继续检验的问题是：**哪些交互经验、状态历史和更新方式，能让预测改善转化为新情境中的物理成功？** 早期补充实验已经显示预测误差降低可以伴随控制退步；单纯降低重建损失或继续增加更新并不保证任务表现提高。

但本次整理没有进行新的文献新颖性检索，不能据此声称上述现象首次被发现、已经解决领域瓶颈或保证论文接收。历史/回放方法的优势目前限于给定协议，且简单反馈控制器很强。

## 仍未解决的问题

| 问题 | 现有证据 | 尚缺什么 |
|---|---|---|
| 物理成功率是否随经验增长？ | 早期身体控制系统有完整曲线 | 修复后图像世界模型的曲线 |
| 更成熟是否学习更快？ | 早期朴素适应总体退步 | 可重复的正迁移与公平的速度比较 |
| 随机探索如何改变有效经验？ | pilot 有接触/位移覆盖 | 正式训练、干预对照、信息指标和下游成功的连接 |
| 历史为何有益？ | 补充历史基线更强 | 参数量/目标数/计算匹配消融，排除控制器与输入差异 |
| 语言是否帮助物理泛化？ | 有合成语音输入 | 有效训练下的语音/碰撞/静音/打乱对照；早期无语言专门消融 |
| 是否为有效世界模型？ | 已有动作条件预测/规划原型 | 修复后可靠的动作条件预测与闭环成功 |
| 是否有 scaling law？ | 有有限交互预算点 | 多尺度设计、预先选定拟合与独立尺度验证 |

“有效操作信息”目前没有已验证的信息论定义。接触、位移和事件覆盖可作代理，但不能直接改名为熵、互信息或可控信息。

## 按门槛推进，不重复扩大失败运行

1. **完整训练路径回归。** 在真实模型/批次/AMP 设置下使用原 `optimizer_update` 和 GradScaler，逐预期参数检查梯度存在与有限性，并在多个正常步骤检查累计更新。注入 overflow，验证同一批次/RNG 的重试和 FP32 回退；验证保存/恢复后的 optimizer、scaler、模型与随机状态。单步零梯度不必自动代表缺陷，但应查明预期更新的参数是否长期不动。
2. **小数据可学习性。** 从随机初始化开始，先确认 tiny overfit 和动作条件预测。分别检查物体区域、运动区域、手/身体与背景；加入 persistence，并使用独立模拟的动作反事实，避免把输入错配当因果预测。记录所有参数模块的变化。
3. **简单闭环任务。** 在固定开发情境中用最简单的搬移/抬起验证模型预测能帮助控制，同时报告随机、简单反馈、hindsight BC、特权参考。记录每步感官、动作、预测和实际结果；先证明任务可行、控制接口正确，再扩大。
4. **冻结新协议。** 新的训练/验证/测试命名空间；预先固定种子、场景数、停止规则、效应阈值和计算预算。旧已查看的测试用于开发，不能继续称为未接触测试。丢弃旧受损权重；合成原始经历可在划分审计后复用。
5. **探索机制研究。** 控制 waypoint 保持时间与噪声，同时记录实际动作熵/相关性/饱和、接触与可重复物理变化。匹配交互预算，并区分经验覆盖与更新量。比较新情境成功率曲线、曲线面积、达到预定阈值的交互量和继续适应的保持损失。
6. **最后才考虑规模规律。** 只有稳定、非地板/天花板的能力出现后，才独立改变数据、模型规模与计算，检验拟合能否预测未参与拟合的规模。当前不拟造幂律指数。

以上是待执行研究计划，未在本次文档整理中完成，也不表示已提交云作业。

## 发表范围

现阶段适合发布工程和研究进展记录。若写论文，应把已完成的早期控制/适应实验与后期世界模型故障审计分开，说明任务帮助、基线、样本单位、重复使用情境以及代码版本。要主张随机探索改善一般物理世界模型，还需要修复后的有效训练、多种子确认、独立新情境、强基线和机制消融。一次性补齐代码不能替代这些实验结果。
